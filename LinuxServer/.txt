Boot Loaders:
    GRUB and GRUB2 
    GRUB-Grand Unified Boot Loader -- it is just a way that the computer transition from bios or uefi booting conditions into the actual operating System itself 
        it is what tells the computer like where is my partions etc 
    they both do the same thing but the GRUB2 is next iteration of GRUB, bellow are some differences:

    grub:
        older as often called GRUB lagacy but it is still on few operating syss i.e slackware 
        difficult to modify 
        boot manu usually displays on boot

    grub2:
        new one
        easy to modify/customizable 
            cat /etc/default/grub
        can boot from an ISO file, USB, UUID, devises(devsda)
        hidden boot manu - if wanna see press/hold shift key on boot
