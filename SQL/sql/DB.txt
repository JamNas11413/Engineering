DATABASE:
    is a collectiojn of data stored in a formate that can easily be accessed 

IN ORDER TO MANAGE OUR DB WE USE A SOFTWARE APPLICATION CALLED DBMS:
    data-base management sys:
        we connects to a dbms and give instructions for quering  and modifing data
        the DBMS will exe our instructions and send results back 
        we have several dbms:
            classified into two categories:
                1) relational{SQL}:
                    in it we store data in form of tables that are linked  to each other using relationships, that is why we call it relational databases
                    Each table stores daa about specific type object like we can have a table for students, customers, produc and so on
                    SQL is the language that we use to work with these relational database management system{RDBMS}
                        several RDBMS:
                            like:
                                mysql
                                sqlserver
                                oracle
                                etc
                                {each rbdms has different flavours of sql but all the implementations are very similer and are based on the standard sql specifcation}


                2) non-relational{NoSQL}:
                    in we don't have tables or relationships
                    it don't use SQL they have their own langs
